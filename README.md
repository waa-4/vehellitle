# veHELLitle

Independent, dark-themed sequence guessing game.

## Install / update

For an existing site, replace **only `index.html`**. Keep your own `stuff.js` and `images` folder so all your added characters remain. The package includes sample placeholder files for brand-new installations.

For a new site, upload `index.html`, `stuff.js`, and `images/` to GitHub Pages.

## Daily mode

Daily Puzzle uses a UTC date seed, eight positions, six attempts and the first four characters in `stuff.js`. The same ordered character list is required for every player to get the same answer. Once you finish, Play Again repeats that day's puzzle and Copy Result copies Wordle-style emoji rows and a link. The mode has no server or progress tracking.

Custom mode lets players set sequence length, attempts and choices. No Job has 14 slots and 10 attempts.

The browser provides the available speech voices; the whispering is only an approximation.
